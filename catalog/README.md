# catalog/

One `<dataset_id>.md` **tearsheet** per warehouse dataset, generated by
`tools/profile.py`: schema, row count, time span, per-column distributions
(with sparklines), spatial coverage, and templated candidate questions.

```
python3 tools/profile.py <dataset_id>     # one
python3 tools/profile.py --all            # every dataset in the warehouse
```

Generated files — safe to delete and regenerate. Re-run after every ingest.
